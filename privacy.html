TTD Booking Assistant Privacy Policy

```

Last updated: September 5, 2026

TTD Booking Assistant is a Chrome extension that helps users fill their own information into supported Tirumala Tirupati Devasthanams (TTD) booking forms.

Information Stored by the Extension

The extension may store information entered by the user, including pilgrim names, contact details, addresses, dates of birth, identification details, passport or visa information, seva information, group-member information, donation-related form information, and extension preferences.

Where the Information Is Stored

The extension stores this information locally in the user's Chrome browser using Chrome's chrome.storage.local API.

The developer does not receive this information.

Data Transmission

TTD Booking Assistant does not transmit the user's saved information to the developer's servers or to third-party analytics or advertising services.

The extension uses the saved information to populate supported booking forms when the user asks it to do so.

Third-Party Websites

When the user uses the extension on a supported TTD booking page, information may be entered into that webpage as part of the user's requested form-filling action.

The extension does not submit the final booking on the user's behalf. Users should review all information before submitting a booking.

Backups

If the extension provides an export or backup feature, exported backup files are encrypted using a passphrase selected by the user. The user controls where exported backup files are stored.

Tracking and Advertising

The extension does not use advertising, analytics, or cross-site tracking.

Data Sharing and Sale

The developer does not sell the user's information or transfer it to third parties for advertising or unrelated purposes.

Data Retention and Deletion

The information remains in the user's browser until the user deletes it using the extension's available controls or removes the extension. Users are responsible for retaining any exported backup files they create.

Security

The extension is designed to keep saved information locally in the user's browser. Users should protect access to their Chrome profile and any exported backup files.

Contact

For privacy questions or concerns, contact: dnaveenkumarmd@gmail.com
```
